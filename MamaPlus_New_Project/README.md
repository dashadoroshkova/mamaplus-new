# МамаПлюс — новый проект сайта

Новая отдельная копия проекта студии «МамаПлюс». Визуальная основа сохранена в прежней мятно-шалфейной гамме с пудровыми акцентами, прежней компоновкой первого экрана, блоками направлений, преимуществ, расписания, цен, онлайн-записи и контактов.

## Состав
- Адаптивная главная страница (`public/index.html`, `public/style.css`).
- Форма онлайн-заявки (`public/app.js`).
- Серверная обработка заявок и проверка повторных заявок / лимита группы (`server.js`).
- Панель администратора по адресу `/admin` для редактирования текстов, направлений, расписания и статусов заявок.
- Настройки Render (`render.yaml`) и пример переменных окружения (`.env.example`).

## Локальный запуск
1. Нужен Node.js 18 или новее.
2. Выполнить `npm install`.
3. Задать `ADMIN_PASSWORD` и длинный `SESSION_SECRET` в переменных окружения.
4. Выполнить `npm start` и открыть `http://localhost:3000`.
5. Панель администратора: `http://localhost:3000/admin`.

## Почтовые уведомления
Чтобы получать уведомления о новых заявках на `kitty94-01@mail.ru`, настройте в Render переменные `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM`, `MAIL_TO`. Не добавляйте пароль почты в GitHub.

## Важно перед публикацией
Заявки и настройки сейчас сохраняются в папку `data`. Для надёжного постоянного хранения на Render нужно подключить постоянный диск или базу данных. До публичного запуска также задайте пароль администратора, секрет сессии, SMTP, актуальные контакты и текст согласия / политику обработки персональных данных.
